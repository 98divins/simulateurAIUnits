# Simulateur AI Units — Oracle HCM

Simulateur de consommation et de coût des AI Units Oracle Fusion HCM (charte SQORUS / Redwood).

## Fichiers
- `index.html` — le simulateur (page autonome, ouvrir dans un navigateur ou servir en statique)
- `support.js` — runtime de rendu (requis par `index.html`)
- `_ds/…` — tokens et bundle du design system Redwood × SQORUS
- `assets/` — logos SQORUS (ne pas recolorer)
- `simulateur-ai-units.standalone.html` — version 1 fichier, sans dépendance, à envoyer par mail ou ouvrir hors-ligne

## Déploiement
GitHub Pages : Settings → Pages → Branch `main`, dossier `/ (root)`. URL : `https://98divins.github.io/simulateurAIUnits/`.
